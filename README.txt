rusauto.tj — Android app source code

Build in Android Studio: open this folder, then Build > Build APK(s).
The APK will be at app/build/outputs/apk/debug/app-debug.apk.

Alternative: upload the CONTENTS of this folder to a GitHub repository, open Actions > Build rusauto.tj APK > Run workflow, and download the rusauto-tj-apk artifact. Extract app-debug.apk and install it on your Redmi.

Note: The debug APK is for personal testing; it is not a Play Store release.
